# Workspace Instructions for Gemini & AI Agents

## Mandatory Change Log Workflow (`gemini_change.log`)
1. **Always read `gemini_change.log` before starting work** to get the summary of the last session, ongoing context, and recent changes.
2. **Always append all changes made during the session to `gemini_change.log`** before concluding the response, detailing:
   - Date & Time
   - Objective / User request
   - Files modified, created, or deleted
   - Technical details of changes
   - Verification results
